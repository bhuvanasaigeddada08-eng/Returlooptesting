# ReturnLoop LPU — Complete Windows Installation & Setup Guide

This guide provides the exact step-by-step instructions to set up, configure, and run **ReturnLoop LPU** locally on a Windows laptop with **zero external hosting, database, or API subscription costs (₹0 Stack)**.

---

## 1. System Requirements & Prerequisites

| Component | Minimum Version | Verified on Workstation | Purpose |
|---|---|---|---|
| **Operating System** | Windows 10 / 11 (64-bit) | Windows 11 | Host environment |
| **Python** | 3.10+ | Python 3.10.11 | Backend Flask API & SQLAlchemy ORM |
| **Node.js** | 18+ | Node.js v25.1.0 | Frontend Vite build & development server |
| **npm** | 9+ | npm 11.6.2 | JavaScript package manager |
| **Java JDK** | OpenJDK 17 or 21 | OpenJDK 21 (Android Studio JBR) | Android Capacitor APK build |
| **SQLite** | Bundled with Python | 3.x embedded | Local ₹0 database engine |

## 2. Directory Structure Overview

The project is structured into two cleanly separated tiers:

```
ReturnLoop/
├── backend/                  # Flask REST API tier
│   ├── app/                  # Application package (models, routes, services, utils)
│   ├── instance/             # Local database directory (returnloop.db)
│   ├── tests/                # Automated pytest test suite (28 passing tests)
│   ├── uploads/              # Local uploaded image storage
│   ├── config.py             # Application configuration with environment variable support
│   ├── requirements.txt      # Python dependencies
│   ├── run.py                # Server entrypoint (binds to 0.0.0.0:5000)
│   └── seed_data.py          # Development database seeding script
├── backend_venv/             # Python virtual environment
├── frontend/                 # React 19 Single Page Application tier
│   ├── src/                  # React source components, pages, context, and styles
│   ├── dist/                 # Production compiled web assets (npm run build)
│   ├── android/              # Native Android project generated by Capacitor
│   ├── capacitor.config.json # Capacitor mobile packaging configuration
│   ├── package.json          # Node dependencies and scripts
│   └── vite.config.js        # Vite bundler configuration (port 5173)
├── docs/                     # Academic and technical documentation
└── backups/                  # SQLite database backup snapshots
```

## 3. Step-by-Step Local Setup

Open **Windows PowerShell** for the commands below.

### Step 3.1: Python Virtual Environment & Backend Dependencies

1. Navigate to the project root:
   ```powershell
   cd c:\Users\bhuva\OneDrive\Desktop\ReturnLoop
   ```
2. Activate the pre-configured virtual environment:
   ```powershell
   .\backend_venv\Scripts\Activate.ps1
   ```
   *(If script execution is disabled on your system, run: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*


1. Open a second PowerShell terminal and navigate to the frontend:

You will run two terminal windows concurrently:

### Terminal 1 — Backend API Server

```powershell

..\backend_venv\Scripts\python.exe run.py
```

- **Network API URL**: `http://0.0.0.0:5000` (accessible to Android devices on the same Wi-Fi)

```powershell
cd c:\Users\bhuva\OneDrive\Desktop\ReturnLoop\frontend

```
- **Local Web Application URL**: `http://localhost:5173`
- The browser will automatically hot-reload when frontend files are modified.

## 8. Common Troubleshooting

| Problem | Cause | Solution |
|---|---|---|
| `Port 5000 already in use` | Another process is holding port 5000 | Find and terminate: `Get-Process -Id (Get-NetTCPConnection -LocalPort 5000).OwningProcess \| Stop-Process -Force` |
| `Port 5173 already in use` | Vite dev server running in another tab | Vite will automatically offer port 5174, or stop the existing terminal process. |
| `CORS Error in Browser` | Backend server is not running | Ensure `run.py` is started in Terminal 1 before interacting with the frontend. |
| `Images not displaying` | Image upload directory missing | Ensure `backend/uploads/` exists (created automatically by Flask if missing). |
| `Script execution disabled` | PowerShell ExecutionPolicy | Run: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` |
