# Prototype Specifications & Testing Plan

## 1. Prototype Structure (The 5 Core Steps)
The prototype was developed iteratively, starting from paper sketches and progressing to functional digital interfaces:
1. **Explore Catalog:** Allows filtering by Campus Block (Block 34, Central Library, UniMall) and Category (Electronics, ID & Cards, Bags, Bottles, Keys). High-value identifiers are masked.
2. **Report Lost Belonging:** Guides the user through Category, Item Title, Brand, Color, General Campus Location, Date Lost, and "Secret Identifying Marks".
3. **Report Found Item:** Designed for rapid submission (under 60 seconds) with options to indicate physical handover to a security post.
4. **Claim Submission:** The claimant must submit descriptive evidence answering: *"What unique mark or proof distinguishes this item as yours?"*
5. **Security Admin Verification Desk:** Campus security reviews the claimant's description against the item's verified condition and issues an immutable handover reference code.

## 2. Testing Plan & User Tasks

### Testing Principles (Adhering to Section 15 & Section 17):
- Hand over the device/paper prototype silently.
- Do not explain how the buttons work.
- If the user gets stuck, note down where and why rather than intervening.

### Lined-Up Test Participants:
- User T1: Hosteller (CSE, 2nd Year) — Has previously lost an item.
- User T2: Day Scholar (Mechanical, 3rd Year) — Commuter perspective.
- User T3: International Student (BBA, 1st Year) — Language & onboarding perspective.
- User T4: Hosteller (Biotech, 2nd Year) — Discovered a lost item recently.
- User T5: Campus Security Guard — Admin verification perspective.

### Scripted User Tasks:
1. **Task 1 (Discovery):** *"Find a lost Casio calculator reported in Central Library."*
2. **Task 2 (Accessibility):** *"Change the language of the application to your native language (Hindi, Telugu, or Punjabi)."*
3. **Task 3 (Claim Submission):** *"Submit an ownership claim for an item, describing a secret mark only you would know."*
4. **Task 4 (Admin Handover):** *"As security desk staff, verify the claim and approve the handover."*
